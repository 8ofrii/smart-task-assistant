# مساعد المهام الذكي — Smart Task Assistant (TypeScript / PostgreSQL)

نظام مساعد ذكي لإدارة المهام وفق الصلاحيات وسياسات الشركة، مبني بلغة TypeScript وقاعدة بيانات PostgreSQL السحابية، مع واجهة مستخدم تفاعلية راقية، ونظام أمان وتحقق صارم من الصلاحيات يعزل الذكاء الاصطناعي عن القرارات التنفيذية.

---

## 📌 الفكرة المعمارية وتطبيق الصلاحيات (Architecture & Security)

```text
رسالة المستخدم (عربي/لهجة) + user_id
              │
              ▼
تحميل هوية ودور المرسل من PostgreSQL مباشرة
(منع أي محاولة انتحال أو ادعاء دور مثل T08)
              │
              ▼
المحلل الدلالي الذكي (LLM Semantic Parser)
(استخراج النية، الوصف، التاريخ، والاسم المستهدف كبيانات فقط)
              │
              ▼
التحقق الصارم بمخطط Zod (Schema Validation)
              │
              ▼
محرك الصلاحيات وقواعد العمل الحتمية في الكود (Deterministic Backend Guard)
(رفض أو قبول العملية برمجياً + تسجيل في audit_logs)
              │
              ▼
معالج التواريخ والمنطقة الزمنية (Asia/Riyadh)
(ترحيل الجمعة للسبت بنفس الوقت وفق الشرط R4)
              │
              ▼
تنفيذ العملية في PostgreSQL / الاسترجاع من السياسة (Zero Hallucination)
              │
              ▼
إرجاع الرد النهائي المهيكل للمستخدم (JSON / UI)
```

## 🛡️ أين تُطبّق الصلاحيات في الكود؟ (Exact Authorization Enforcement)

تطبيقاً للشرط الإلزامي **(R3)** بأن تُطبّق الصلاحيات في الكود وليس في تعليمات الـ Prompt فقط:

1. **دوال فحص الصلاحيات الأساسية (`src/services/authorization.service.ts`):**
   - [`canAssignTask`](file:///c:/Users/z40/Downloads/smart-task-assistant-ts-v5/src/services/authorization.service.ts#L3-L11): تمنع الموظف من إسناد مهام لغيره، وتلزم المشرف بحدود قسمه، وتمنح المدير حرية الإسناد للجميع.
   - [`canViewTaskOwner`](file:///c:/Users/z40/Downloads/smart-task-assistant-ts-v5/src/services/authorization.service.ts#L13-L21): تمنع أي شخص من رؤية مهام غيره، عدا المشرف لموظفي قسمه، والمدير للجميع.
   - [`canViewDepartment`](file:///c:/Users/z40/Downloads/smart-task-assistant-ts-v5/src/services/authorization.service.ts#L23-L33): التحقق من عرض مهام القسم للمشرف المعني فقط أو المدير.
   - [`canViewAllTasks`](file:///c:/Users/z40/Downloads/smart-task-assistant-ts-v5/src/services/authorization.service.ts#L35-L37): حصرية عرض كافة مهام الشركة للمدير فقط (`sender.role === "manager"`).

2. **التنفيذ والحظر في طبقة المهام والتسجيل الأمني (`src/services/task.service.ts`):**
   - السطور (94-115): عند استدعاء `createTask`، إذا فشل فحص الصلاحية يتم تسجيل المحاولة في جدول `audit_logs` برمز خطأ محدد وإرجاع رد بالرفض مع إشعار بالسبب.
   - السطور (220-274): عند استدعاء `listTasks`، يتم التحقق الحتمي وإرجاع 403 وحظر العرض فوراً في حال عدم استيفاء الشروط.

3. **حماية نقطة الوصول (`src/routes/chat.route.ts`):**
   - السطور (35-42): يتم جلب بيانات الموظف ودوره حصرياً بالمعرّف الرقمي `user_id` من قاعدة البيانات. أي ادعاء للمستخدم في نص الرسالة (مثل "أنا المدير") يتم تجاهله أمنياً بالكامل.

## 🚀 التشغيل السريع (Quickstart)

### 1. تثبيت الاعتماديات
```bash
npm install
```

### 2. إعداد المتغيرات البيئية
انسخ ملف الإعدادات:
```bash
copy .env.example .env
```
(أو `cp .env.example .env` على Linux/macOS)

قم بضبط مفاتيح الاتصال في `.env` (قاعدة بيانات PostgreSQL السحابية، ومفتاح OpenAI أو Gemini أو OpenRouter).

### 3. تهيئة قاعدة البيانات والجداول
```bash
npm run db:init
```
يقوم الأمر بإنشاء جداول `employees`، `tasks`، `audit_logs` وإدخال الموظفين الستة.

### 4. تشغيل السيرفر
```bash
npm start
```
يعمل السيرفر على: **`http://localhost:3000`**

## 💻 واجهة المستخدم المتقدمة (Web UI)

افتح المتصفح على:
```text
http://localhost:3000
```

### الميزات المتاحة في الواجهة:
1. **شعار الشركة:** تم إدراج الشعار الرسمي للشركة بنسخة متجهة فائقة الدقة والوضوح (`/company-logo.svg` و `/company-logo.png`).
2. **شريط تبديل الموظفين:** إمكانية التبديل بنقرة واحدة بين الموظفين الستة وملاحظة تغير الصلاحيات الفعلي.
3. **مختبر الاختبارات الرسمية (Official 10 Tests Suite):** تبويب مخصص يحتوي على بطاقات الحالات الـ 10، مع إمكانية تجربة كل حالة بنقرة واحدة، أو الضغط على **"تشغيل جميع الاختبارات تلقائياً"** لمشاهدة النتائج المعتمدة مباشرة.
4. **مستكشف مهام قاعدة البيانات الحية (Live PostgreSQL Tasks):** عرض فوري للمهام المسجلة داخل PostgreSQL وفق صلاحيات المستخدم النشط.
5. **سجل العمليات والتدقيق الأمني (Audit Log Viewer):** فحص مباشر لمحاولات تجاوز الصلاحيات المحظورة (مثل محاولة فهد في T08 أو T02) وسجلات المهام المنفذة.
6. **دعم كامل للغتين:** التبديل الفوري بين العربية والإنجليزية مع تعديل اتجاه الواجهة (RTL/LTR).
7. **الوضع الداكن والفاتح:** دعم كامل للثيمين (Light / Dark) مع حفظ التفضيل محلياً.
